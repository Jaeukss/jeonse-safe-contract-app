# MVP Scope: 관악구+강서구 전세계약 위험진단 프로토타입

## 목표

관악구+강서구 전월세·매매 실거래가와 건축물대장 데이터를 기반으로, OCR이 불완전해도 사용자 수기 입력·선택지 입력으로 보완해 최종 위험진단까지 끊기지 않는 MVP를 만든다.

## 고정 범위

| 구분 | 내용 |
| --- | --- |
| 지역 | 서울시 관악구 + 강서구 |
| 사용자 입력 | 주소, 주택유형, 보증금, 월세, 전용면적, 층, 계약 단계 |
| 시세 데이터 | 서울 실거래가 기반 관악구+강서구 전월세·매매 데이터 |
| 건축물 데이터 | 관악구+강서구 건축물대장 |
| 문서 입력 | OCR 텍스트 추출 + 불확실 항목 사용자 보완 입력 |
| 위험 산출 | 전세가율, 시세괴리율, 권리관계·문서 위험 점수 |
| 설명 | 위험 신호별 템플릿 + 최소 RAG 근거 |
| 출력 | 위험등급, 신뢰도, 위험 사유, 확인 필요 정보, 다음 행동 |
| 데이터 입력 전 UX | 문서 준비 안내, 계약 전 행동 체크, 보증금 조정 시뮬레이터 |

## OCR 대상 문서

| 문서 | MVP 처리 방식 |
| --- | --- |
| 등기부등본 | OCR 텍스트 추출 + 키워드 파싱 + 사용자 보완 입력 |
| 건축물대장 | OCR 텍스트 추출 + 공공데이터 매칭 + 사용자 보완 입력 |
| 중개대상물 확인설명서 | OCR 텍스트 추출 + 사용자 보완 입력 |
| 임대차계약서 | 선택 구현, 기본 진단 흐름에서는 제외 |

## 입력 안정화 원칙

```text
문서 업로드
-> OCR 텍스트 추출
-> 핵심 항목 자동 추출
-> 추출 실패/불확실/충돌 항목 표시
-> 사용자 수기 입력 또는 선택지 입력으로 보완
-> 최종 진단값 확정
-> 진단 스냅샷 생성
-> 위험 진단 및 리포트 생성
```

## UX 원칙

- 전 버전 UI/UX의 장점인 쉬운 문서 준비 안내와 단계형 입력 흐름을 유지한다.
- 일반 임차인은 쉬운 설명과 다음 행동 중심으로 안내한다.
- 공인중개사/컨설턴트는 근거, 표, 스냅샷, 출처 중심으로 확인할 수 있게 한다.
- 보증금 조정 시뮬레이터는 실제 진단 전 위험 방향성을 이해시키는 간이 도구로만 사용한다.
- 실제 판정은 OCR 결과, 사용자 보완 입력, 공공데이터, 유사 거래 기반 가격 예측을 종합해 산출한다.

## 제외 항목

- 등기부등본 완전 자동 파싱
- 실시간 등기소·정부24 API 연동
- HUG 보증 가능성 정밀 판정
- 전국 단위 모델
- GNN

## 구현 우선순위

1. 관악구+강서구 데이터 전처리
2. Streamlit 기본 입력 화면
3. Raw Data Store
4. OCR 업로드·텍스트 추출
5. OCR 결과 확인 및 보완 입력 화면
6. OCR/사용자 보완 입력 병합
7. 충돌 감지·사용자 확인
8. 진단 스냅샷 저장
9. 유사 거래 검색
10. 전세가·매매가 예측
11. 전세가율·시세괴리율 계산
12. 위험 점수·등급 산출
13. 리포트 출력
14. 샘플 케이스 테스트
15. 발표용 구조 정리
