# MVP Scope: 관악구 전세계약 위험진단 프로토타입

## 목표

관악구 전월세·매매 실거래가와 건축물대장 샘플을 기반으로, OCR이 불완전해도 체크박스 보완을 통해 최종 위험진단까지 끊기지 않는 MVP를 만든다.

## 고정 범위

| 구분 | 내용 |
| --- | --- |
| 지역 | 서울시 관악구 |
| 사용자 입력 | 주소, 주택유형, 보증금, 월세, 전용면적, 층, 계약 단계 |
| 시세 데이터 | 관악구 전월세·매매 실거래가 |
| 건축물 데이터 | 관악구 건축물대장 |
| 문서 입력 | OCR 업로드 + 체크박스 수동 보완 |
| 위험 산출 | 전세가율, 시세괴리율, 권리관계·문서 위험 점수 |
| 설명 | 위험 신호별 템플릿 + 최소 RAG 근거 검색 |
| 출력 | 위험등급, 신뢰도, 위험 사유, 확인 필요 정보, 다음 행동 |

## OCR 대상 문서

| 문서 | MVP 처리 방식 |
| --- | --- |
| 등기부등본 | 텍스트 추출 + 키워드 파싱 + 체크박스 보완 |
| 건축물대장 | 텍스트 추출 + 공공데이터 매칭 + 체크박스 보완 |
| 중개대상물 확인설명서 | 텍스트 추출 + 체크박스 보완 |
| 임대차계약서 | 선택 구현, 기본 진단 흐름에서는 제외 |

## 제외 항목

- 등기부등본 완전 자동 파싱
- 실시간 등기소·정부24 API 연동
- HUG 보증 가능성 정밀 판정
- 전국 단위 모델
- GNN

## 구현 우선순위

1. 관악구 데이터 전처리
2. Streamlit 기본 입력 화면
3. Raw Data Store
4. OCR 업로드·텍스트 추출
5. 체크박스 보완 화면
6. OCR/체크박스 병합
7. 충돌 감지·사용자 확인
8. 진단 스냅샷 저장
9. 유사 거래 검색
10. 전세가·매매가 예측
11. 전세가율·시세괴리율 계산
12. 위험 점수·등급 산출
13. 리포트 출력
14. 샘플 케이스 테스트
15. 발표용 구조 정리
