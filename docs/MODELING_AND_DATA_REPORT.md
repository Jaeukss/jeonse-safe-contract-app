# 모델링 및 데이터 처리 리포트

작성일: 2026-05-21

## 목적

관악구 MVP를 관악구+강서구 범위로 확장하고, 제공된 서울 전체 실거래가 2년치, 건축물대장, 주택가격, RAG 문서를 MVP 산출물로 정리했다.

핵심 목적은 다음과 같다.

- 매매가와 전세보증금 기준값을 산출해 전세가율과 시세괴리율 계산에 사용한다.
- 건축물대장 표제부/전유부/전유공용면적/층별개요/총괄표제부에서 주소, 용도, 면적, 사용승인일 등 진단 보조 정보를 만든다.
- 주택가격 데이터는 매매 실거래가가 부족할 때만 보조 가격 참고값으로 사용한다.
- 법령, 계약서, 중개문서, HUG, 예방 안내 자료는 RAG 설명 근거로 변환한다.
- 정형 데이터 기반 가격 예측과 비정형 문서 분석을 분리한다.

## 구조

```text
정형 데이터: 실거래가 / 건축물대장 / 주택가격
-> 머신러닝/통계 모델
-> 전세보증금 기준값, 매매가 기준값, 전세가율 계산

비정형 데이터: 계약서 / 등기부등본 / 중개대상물 확인설명서 / PDF 스캔본
-> OCR + 사용자 입력 보완 + LLM/RAG
-> 권리관계 위험 신호, 확인 필요 문서, 쉬운 설명

최종 판단
-> 가격 지표 + 문서 신호 + 사용자 입력 보완 + 규칙 기반 위험 점수 합산
```

| 데이터 | 처리 방법 | 결과 |
| --- | --- | ---: |
| 서울 실거래가 2년치 | 서울 전체 ZIP 2개를 통합하고 관악구+강서구 holdout 평가셋 생성 | 전세 43,426건 / 매매 23,623건 |
| 건축물대장 표제부 | 관악구+강서구 필터링, 핵심 컬럼 정리 | 57,016건 |

## 1차 모델 비교

가격 예측은 아래 후보를 비교했다.

| 후보 | 성격 | 설명 |
| --- | --- | --- |
| 계층형 유사거래 중앙값 | ML/통계 baseline | 구, 동, 주택유형, 건물명, 도로명, 지번, 면적 구간 순서로 유사거래 중앙값 사용 |
| Ridge log-linear | 머신러닝 | 정형 피처를 해시 인코딩하고 로그 가격을 Ridge 방식으로 예측 |
| MLP log-price | 딥러닝 | 1-hidden-layer MLP를 `numpy`로 구현해 로그 가격 예측 |

학습 범위는 서울 전체 실거래가 2년치이고, 평가는 관악구+강서구 holdout으로 수행했다.

| 대상 | 최고 모델 | MAE | RMSE | MAPE | MdAPE |
| --- | --- | ---: | ---: | ---: | ---: |
| 전세보증금 | 계층형 유사거래 중앙값 | 44,203,094원 | 71,918,349원 | 22.87% | 9.09% |
| 매매가 | 계층형 유사거래 중앙값 | 64,341,172원 | 145,239,599원 | 13.95% | 6.34% |

이번 데이터에서는 딥러닝 MLP보다 계층형 유사거래 중앙값이 더 안정적이었다.

| 대상 | 중앙값 MdAPE | Ridge MdAPE | MLP MdAPE |
| --- | ---: | ---: | ---: |
| 전세보증금 | 9.09% | 18.81% | 20.03% |
| 매매가 | 6.34% | 26.46% | 25.18% |

## 2차 세그먼트 개선 실험

전세보증금은 저가 구간, 다가구, 일부 법정동/월 구간에서 MAPE가 크게 튀는 문제가 확인되어 외부자료 없이 가능한 세그먼트 개선을 추가 실험했다.

비교 후보:

- 기존 서울 2년치 baseline
- 관악구/강서구 세그먼트 중앙값
- 세그먼트별 비율 보정
- 세그먼트별 잔차 보정
- 로컬 중앙값/비율 보정 라우팅

결과:

| 대상 | 선택 모델 | MAE | RMSE | MAPE | MdAPE | baseline 대비 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 전세보증금 | 세그먼트 잔차 보정 baseline | 44,205,317원 | 71,379,371원 | 23.14% | 9.09% | MAE 약 73,579원 개선, MAPE 0.03%p 개선 |
| 매매가 | 기존 서울 2년치 baseline | 64,462,850원 | 145,187,818원 | 13.96% | 6.34% | 개선 모델보다 baseline이 안정적 |

해석:

- 전세는 세그먼트 보정으로 아주 소폭 개선되지만, 구조적 오차를 해결할 만큼 크지는 않다.
- 매매는 기존 baseline을 유지하는 것이 더 낫다.
- 주택유형별 분리와 저가 구간 보정만으로는 전세 모델의 큰 오차를 충분히 줄이지 못했다.
- 다음 성능 개선에는 전세가격지수, 기준금리/대출금리, 신규/갱신 구분, 역세권/학교 거리 같은 외부 피처가 필요하다.

## 최종 선택

현재 MVP 가격 기준 모델은 아래처럼 적용한다.

| 대상 | 적용 |
| --- | --- |
| 전세보증금 | 기존 baseline + 세그먼트 잔차 보정 결과를 참고하되, 리포트에는 시세 신뢰도와 고오차 구간 경고를 함께 표시 |
| 매매가 | 기존 서울 2년치 계층형 유사거래 중앙값 baseline 유지 |

모델 성능상 “딥러닝이 더 낫다”는 결론은 나오지 않았다. 현재 프로젝트에서는 정형 가격 예측은 ML/통계 기반 모델, 계약서·등기부등본·문서 해석은 OCR + LLM/RAG로 분리하는 구조가 맞다.

## 주의사항

전세보증금 모델의 평균 MAPE는 20%를 초과한다. 따라서 앱 리포트에는 아래 원칙을 유지해야 한다.

```text
시세 예측값은 확정 감정가가 아니라 유사거래 기반 참고값입니다.
일부 물건은 계약갱신, 월세 혼합, 신축 여부, 층, 호수, 건물 상태에 따라 오차가 커질 수 있습니다.
최신 실거래가, 등기부등본, 건축물대장, 보증 가능 여부를 함께 확인해야 합니다.
```

## 향후 보강

지금 진행은 비효율적이지 않다. 데이터가 늘어나면 전체를 처음부터 다시 설계할 필요 없이 아래만 재실행하면 된다.

```text
1. 실거래가/외부 피처 추가
2. 전처리 스크립트 재실행
3. 벤치마크 재실행
4. 세그먼트 개선 실험 재실행
5. 성능 기준을 넘는 모델만 교체
```

우선 추가가 필요한 데이터는 전세가격지수, 기준금리/대출금리, 신규/갱신 구분이 있는 전월세 데이터, 역세권/학교 거리 등 입지 파생 데이터다.
