# 모델링 및 데이터 처리 리포트

작성일: 2026-05-21

## 목적

관악구 MVP를 관악구+강서구 범위로 확장하고, 제공된 서울 전체 실거래가 2년치와 건축물대장/주택가격/RAG 문서를 실제 MVP 산출물로 정리했다.

핵심 목적은 다음과 같다.

- 매매가와 전세보증금 기준값을 산출해 전세가율과 시세괴리율 계산에 사용한다.
- 건축물대장 표제부/전유부/전유공용면적/층별개요/총괄표제부에서 주소, 용도, 면적, 사용승인일, 호실 정보를 확인한다.
- 주택가격 데이터는 매매 실거래가가 부족할 때만 보조 가격 피처로 사용한다.
- 법령, 계약서, 중개문서, HUG, 예방 안내 자료는 RAG 설명 근거로 변환한다.
- 정형 데이터 기반 가격 예측과 비정형 문서 분석을 분리한다.

## 구조

이번 MVP의 최종 AI 구조는 아래처럼 분리한다.

```text
정형 데이터
실거래가 / 건축물대장 / 주택가격
→ 머신러닝·통계 모델
→ 전세보증금 기준값, 매매가 기준값, 전세가율 계산

비정형 데이터
계약서 / 등기부등본 / 중개대상물 확인설명서 / PDF·스캔본
→ OCR + LLM/RAG
→ 위험 조항, 권리관계, 제출·확인 문서 설명

최종 판단
→ 가격 지표 + 문서 신호 + 사용자 보완 입력 + 규칙 기반 점수 합산
```

| 데이터 | 처리 방법 | 결과 |
| --- | --- | --- |
| 서울 실거래가 2년치 | 서울 전체 ZIP 2개에서 관악구+강서구를 필터링하고, 거래유형/주택유형/면적/금액 단위를 정규화 | 평가용 순수 전세 43,426행, 매매 23,623행 |
| 건축물대장 표제부 | 서울 ZIP에서 관악구+강서구만 추출하고 핵심 컬럼만 유지 | 57,016행 |

| RAG 문서 | PDF/DOC를 텍스트/Markdown/JSONL chunk로 변환 | 11개 문서, 213개 chunk |

## 모델링 방법

가격 예측은 세 가지 후보를 비교했다.

| 후보 | 성격 | 설명 |
| --- | --- | --- |
| 계층형 유사거래 중앙값 | ML/통계 기준 모델 | 구, 동, 주택유형, 건물명, 도로명, 지번, 면적 구간 순서로 유사거래 중앙값을 사용 |
| Ridge log-linear | 머신러닝 | 정형 피처를 해시 인코딩하고 로그가격을 Ridge 방식으로 예측 |
| MLP log-price | 딥러닝 실험 | 1-hidden-layer MLP를 `numpy`로 구현해 로그가격을 예측 |

학습 범위는 서울 전체 실거래가 2년치이며, 평가는 관악구+강서구 holdout으로 수행했다.

## 성능평가 결과

| 대상 | 최고 모델 | MAE | RMSE | MAPE | 중앙 오차율 |
| --- | --- | ---: | ---: | ---: | ---: |
| 전세보증금 | 계층형 유사거래 중앙값 | 44,203,094원 | 71,918,349원 | 22.87% | 9.09% |
| 매매가 | 계층형 유사거래 중앙값 | 64,341,172원 | 145,239,599원 | 13.95% | 6.34% |

비교 결과, 이번 데이터에서는 딥러닝 MLP보다 유사거래 기반 계층형 중앙값 모델이 더 높게 나왔다.

| 대상 | 계층형 중앙값 MdAPE | Ridge MdAPE | MLP MdAPE |
| --- | ---: | ---: | ---: |
| 전세보증금 | 9.09% | 18.81% | 20.03% |
| 매매가 | 6.34% | 26.46% | 25.18% |

## 최종 선택

최종 가격 기준 모델은 **계층형 유사거래 중앙값 모델**로 선택했다.

선택 이유:

- 관악구+강서구 평가에서 가장 낮은 중앙 오차율을 보였다.
- 부동산 가격처럼 이상치가 큰 데이터에서는 평균보다 중앙값 기반 모델이 안정적이다.
- 설명 가능성이 높아 MVP 리포트에서 “비슷한 거래 기준”으로 설명하기 쉽다.
- 전세보증금은 평균 MAPE가 20%를 넘지만 중앙 오차율은 9.09%로 MVP 참고값 기준에는 사용할 수 있다.

## 주의사항

전세보증금 모델의 평균 MAPE는 22.87%로, 초기 경고선 20%를 초과했다. 따라서 리포트에는 다음 문구를 포함해야 한다.

```text
시세 예측값은 확정 감정가가 아니라 유사거래 기반 참고값입니다.
일부 물건은 계약갱신, 월세 혼합, 신축 여부, 층/호수, 건물 상태에 따라 오차가 커질 수 있습니다.
최신 실거래가와 등기부등본, 건축물대장, 보증 가능 여부를 함께 확인해야 합니다.
```

## 향후 보강

지금 진행하는 것은 비효율적이지 않다. 데이터가 늘어나면 앱 전체를 다시 만들 필요 없이 아래만 다시 실행하면 된다.

```text
1. 실거래가 원천 데이터 추가
2. 전처리 스크립트 재실행
3. 모델 벤치마크 재실행
4. 더 좋은 모델로 교체
```

성능 개선을 위해 가장 필요한 추가 데이터는 서울 전체 3~5년치 실거래가다. 건축물대장과 RAG 문서는 현재 MVP 기준으로 충분하다.
