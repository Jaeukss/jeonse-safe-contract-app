# Business Plan Workflow

## MVP 메시지

전세계약 위험진단에서 중요한 것은 완벽한 OCR보다 진단까지 끊기지 않는 입력 안정화입니다. 본 MVP는 관악구+강서구 데이터로 범위를 확장하고 OCR, 사용자 입력 보완, 충돌 확인, 스냅샷, 위험점수, 리포트를 연결합니다.

## 최종 포지셔닝

HUG/KB가 결과형 전세안전진단이라면, 본 서비스는 OCR 오류·서류 누락·입력 충돌까지 감안해 사용자가 계약 전 확인해야 할 정보를 끝까지 정리해주는 증거 기반 전세계약 위험진단 AI Agent입니다.

## 데이터 입력 전 UX

1. 전 버전 UI/UX의 장점인 문서 준비 안내와 진행 순서를 유지한다.
2. 사용자를 `일반 임차인`과 `공인중개사/컨설턴트`로 나눠 설명 밀도를 조절한다.
3. 계약 전 행동 체크를 통해 최신 등기부등본 발급, 건축물대장 대조, 중개사 질문, HUG 보증 확인을 유도한다.
4. 보증금 조정 시뮬레이터로 보증금이 내려가거나 채권최고액이 반영될 때 전세가율과 간이 위험등급이 어떻게 바뀌는지 보여준다.
5. 실제 진단 입력 이후에는 `OCR 결과 확인 -> 사용자 보완 입력 -> 충돌 확인 -> 스냅샷 저장 -> 진단 리포트` 흐름으로 처리한다.

## 사업 확장 로드맵

| 단계 | 범위 | 목표 |
| --- | --- | --- |
| 1단계 | 관악구 | MVP 검증, 입력 안정화 UX 확인 |
| 2단계 | 관악구 + 강서구 | 위험 사례 다양화, 데이터 커버리지 확대 |
| 3단계 | 서울 | 자치구별 시세 모델과 공공데이터 매칭 강화 |
| 4단계 | 수도권 | 보증보험/대출 가능성, 전문가 상담 연계 |

## 차별점

- 결과만 보여주는 진단이 아니라 계약 전 행동을 안내하는 워크플로우
- 보증금 조정 시 전세가율과 위험등급 변화를 보여주는 시뮬레이터
- 일반 임차인용 쉬운 설명과 전문가용 근거·스냅샷 중심 UX
- OCR 실패를 전제로 한 사용자 직접 입력 보완 UX
- 원본 입력을 출처별로 저장하는 Raw Data Store
- 충돌 감지와 사용자 확정값 기반 스냅샷
- 위험 점수표 기반 설명 가능한 판정
- RAG/Agent/모델은 MVP 수준으로 축소해 일주일 내 구현 가능
