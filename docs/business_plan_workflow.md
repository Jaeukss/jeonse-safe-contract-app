# Business Plan Workflow

## MVP 메시지

전세계약 위험진단에서 중요한 것은 완벽한 OCR보다 진단까지 끊기지 않는 입력 안정화입니다. 본 MVP는 관악구 데이터로 범위를 제한하고 OCR, 체크박스, 충돌 확인, 스냅샷, 위험점수, 리포트를 연결합니다.

## 사업 확장 로드맵

| 단계 | 범위 | 목표 |
| --- | --- | --- |
| 1단계 | 관악구 | MVP 검증, 입력 안정화 UX 확인 |
| 2단계 | 관악구 + 강서구 | 위험 사례 다양화, 데이터 커버리지 확대 |
| 3단계 | 서울 | 자치구별 시세 모델과 공공데이터 매칭 강화 |
| 4단계 | 수도권 | 보증보험/대출 가능성, 전문가 상담 연계 |

## 차별점

- OCR 실패를 전제로 한 체크박스 보완 UX
- 원본 입력을 출처별로 저장하는 Raw Data Store
- 충돌 감지와 사용자 확정값 기반 스냅샷
- 위험 점수표 기반 설명 가능한 판정
- RAG/Agent/모델은 MVP 수준으로 축소해 일주일 내 구현 가능
