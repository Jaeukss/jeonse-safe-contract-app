# Demo Script

1. `streamlit run app.py`로 앱을 실행한다.
2. 첫 화면에서 문서 준비 카드와 계약 전 행동 체크를 보여준다.
3. 보증금 조정 시뮬레이터에서 보증금 2.5억과 2.3억의 전세가율 변화를 비교한다.
4. 사용자 모드를 `일반 임차인` 또는 `공인중개사/컨설턴트`로 전환해 설명 밀도가 달라지는 기획 의도를 설명한다.
5. 주소를 `서울시 관악구 신림동` 또는 `서울 강서구 화곡동`으로 입력한다.
6. 보증금, 면적, 주택유형을 입력한다.
7. 등기부등본/건축물대장 PDF 또는 TXT를 업로드한다.
8. OCR 결과가 부족한 항목을 사용자 직접 입력으로 보완한다.
9. OCR과 사용자 보완 입력이 충돌하면 사용자 확인 화면에서 값을 확정한다.
10. 리포트에서 위험등급, 전세가율, 시세괴리율, 핵심 위험 신호를 설명한다.
11. Markdown 리포트를 다운로드한다.

발표 포인트:

- OCR이 실패해도 사용자 입력 보완으로 진단이 계속된다.
- 모든 입력은 Raw Data Store에 남고, 진단 시점의 스냅샷이 별도로 저장된다.
- 관악구+강서구 실거래가 기준 유사 거래 수와 시세 신뢰도를 함께 보여준다.
- HUG/KB와 다르게 결과형 진단만이 아니라 서류 누락, OCR 오류, 입력 충돌을 수습하는 계약 전 워크플로우를 강조한다.
