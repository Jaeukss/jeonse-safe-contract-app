# Demo Script

1. `streamlit run app.py`로 앱을 실행한다.
2. 주소를 `서울시 관악구 신림동`으로 입력한다.
3. 보증금, 면적, 주택유형을 입력한다.
4. 등기부등본/건축물대장 PDF 또는 TXT를 업로드한다.
5. OCR 결과가 부족한 항목을 체크박스로 보완한다.
6. OCR과 체크박스가 충돌하면 사용자 확인 화면에서 값을 확정한다.
7. 리포트에서 위험등급, 전세가율, 시세괴리율, 핵심 위험 신호를 설명한다.
8. Markdown 리포트를 다운로드한다.

발표 포인트:

- OCR이 실패해도 체크박스 보완으로 진단이 계속된다.
- 모든 입력은 Raw Data Store에 남고, 진단 시점의 스냅샷이 별도로 저장된다.
- 관악구 실거래가 기준 유사 거래 수와 시세 신뢰도를 함께 보여준다.
