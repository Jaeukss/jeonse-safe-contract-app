# 임차인용 앱 화면 근거 정리

이 문서는 배포 앱 화면에 들어간 안내 문구와 링크의 근거를 정리한다. 앱은 임차인이 실제 계약 전에 사용하는 도구로 구성하고, 학습·성능평가·포트폴리오 설명은 별도 문서로 분리한다.

## 앱에서 요구하는 주요 파일

| 파일 | 임차인에게 필요한 이유 | 앱 내 안내 링크 |
| --- | --- | --- |
| 등기부등본 또는 등기사항전부증명서 | 소유자, 근저당권, 압류, 가압류, 신탁등기 등 권리관계 확인 | 대법원 인터넷등기소 `https://www.iros.go.kr/` |
| 건축물대장 | 주용도, 면적, 층, 사용승인일, 위반건축물 표시 여부 확인 | 세움터 `https://www.eais.go.kr/` |
| 임대차계약서 초안 또는 표준계약서 | 보증금, 잔금일, 특약, 근저당 말소 조건 확인 | 법무부 자료실 `https://www.moj.go.kr/moj/315/subview.do` |
| 중개대상물 확인설명서 | 중개사가 설명한 권리관계와 실제 문서의 일치 여부 확인 | 공인중개사법 `https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=273341` |
| HUG 반환보증 신청 준비서류 | 보증 가입 가능성, 보증한도, 제출서류 확인 | 모바일 HUG `https://onestop.khug.or.kr/view/biz/apply/goods001` |

## 공식 근거

- 정부24 점검 안내 페이지는 건축물대장 대체 발급 사이트로 세움터를 안내한다.
- HUG 모바일 페이지는 전세보증금반환보증 상품, 제출서류, 보증한도, 가입채널을 안내한다.
- 법무부 자료실은 주택임대차 관련 자료를 제공하는 정부 사이트이다.
- 국가법령정보센터는 주택임대차보호법, 공인중개사법 등 법령 원문을 제공한다.
- 국토교통부 전세계약 유의사항 리플렛과 서울시 전세사기 예방 안내는 전세계약 전 확인사항의 근거 문서로 사용한다.

## 앱과 GitHub 문서의 역할 분리

### 배포 앱

- 임차인이 계약 전에 입력해야 하는 최소 정보만 받는다.
- 업로드할 문서와 발급 위치를 안내한다.
- 위험등급, 위험 사유, 지금 해야 할 일, 공식 확인 링크를 보여준다.
- CSV, 모델 가중치, 성능평가 JSON 같은 개발자용 자료는 앱 화면에 직접 노출하지 않는다.

### GitHub 포트폴리오

- 데이터 전처리 코드
- 공식문서 RAG 구축 코드
- 건축물대장 ZIP 처리 코드
- 모델 학습과 평가 코드
- 평가 결과 JSON과 문서
- 대회 제출용 기술 설명
