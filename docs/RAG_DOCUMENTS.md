# RAG 문서 데이터 설명

`data/rag_documents_mvp.json`은 위험 진단 결과를 설명하기 위한 근거 문서 데이터다. 원문 전체를 복제하지 않고, MVP에서 필요한 근거 요약, 공식 URL, 위험 키, 응답 규칙을 chunk 단위로 정리했다.

공식 출처 원장은 `data/rag_official_sources.json`에 별도로 정리했다. 제출용 링크표는 `docs/OFFICIAL_RAG_SOURCE_LINKS.md`에서 확인할 수 있다.

## 포함 문서

- 주택임대차보호법
- 주택임대차보호법 시행령
- 공인중개사법
- 부동산등기법 관련 안내 자료
- 건축물대장 확인 안내 자료
- HUG 전세보증금반환보증 안내문
- 국토교통부 전세사기 예방 체크리스트
- 지자체 전세사기 예방 안내문
- 주택임대차 표준계약서
- 중개대상물 확인설명서 양식

## 앱에서의 활용

진단 엔진은 위험 신호별 key를 만든 뒤 RAG 문서의 `risk_keys`와 연결한다. 예를 들어 `mortgage` 신호는 근저당권, HUG 보증, 표준계약서 특약 근거와 연결되고, `violation` 신호는 건축물대장 확인 안내와 연결된다.

## 출처 검증 기준

- 법령은 법제처 국가법령정보센터의 현재 법령 또는 법령명 URL을 우선 사용한다.
- 보증 조건은 HUG 공식 상품 안내와 모바일HUG 신청 안내를 함께 보존한다.
- 표준계약서는 법무부 주택임대차표준계약서 페이지와 자료실을 기준으로 한다.
- 지자체 예방 안내는 서울주거포털 전세사기 피해 예방·지원 안내와 PDF 안내서를 사용한다.
- 건축물대장은 정부24 발급·열람 안내와 공공데이터포털 건축물대장 정보 서비스를 함께 연결한다.
