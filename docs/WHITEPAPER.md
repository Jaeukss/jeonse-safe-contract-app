# 전세계약 안심진단 AI Agent 백서

## 1. 개요

전세계약 안심진단 AI Agent는 임차인이 전세계약 전 확인해야 하는 핵심 문서와 공공데이터를 한 화면에서 점검하도록 돕는 MVP다. 사용자가 계약 주소, 주택유형, 전세보증금, 전용면적, 계약 단계와 문서 확인 여부를 입력하면 앱은 실거래가 기반 지표와 문서 기반 위험 신호를 종합해 위험 등급, 근거, 다음 행동을 제공한다.

본 MVP는 2026년 국토교통 데이터활용 경진대회 제출을 목표로 한다. 심사 환경에서 바로 실행할 수 있도록 seed 데이터를 포함하되, 운영 단계에서는 공공데이터포털 API 수집 결과로 교체할 수 있는 구조를 유지했다.

## 2. 해결하려는 문제

전세계약 위험은 단일 문서만으로 판단하기 어렵다. 전세가율, 주변 시세, 등기부 권리관계, 건축물대장상 용도와 위반 여부, 보증보험 가능성, 계약서 특약, 중개대상물 확인설명서가 함께 검토되어야 한다. 특히 고령자나 초보 임차인은 여러 기관 사이트와 문서를 오가며 확인해야 하므로 누락 위험이 크다.

이 MVP는 문서 업로드 후 순서대로 진행하는 인앱 흐름을 제공해 확인 절차를 단순화하고, 위험 신호가 왜 문제인지 공식 근거 문서와 함께 설명한다.

## 3. MVP 기능

1. 계약 문서 업로드 또는 텍스트 입력
2. 등기부등본, 건축물대장, 확인설명서의 주요 위험 신호 추출
3. 사용자 입력 기반 전세계약 정보 정리
4. 실거래가 seed 데이터 기반 전세가율, 시세괴리율, 유사거래 수 계산
5. 건축물대장 seed 데이터 기반 주용도, 면적, 위반건축물 여부 확인
6. RAG 근거 문서와 위험 신호 연결
7. 위험 등급, 신뢰도, 다음 행동, 공식 출처 링크 제공

## 4. 데이터셋

### 4-1. 사용자 입력 샘플 데이터

- 파일: `data/user_input_samples.csv`
- 주요 필드: 주소, 법정동코드, 주택유형, 전세보증금, 월세 여부, 월세, 전용면적, 층, 계약 단계
- 활용: 앱 입력 폼 초기값, 시연 케이스, 진단 로직 테스트

### 4-2. 실거래가 데이터

- 파일: `data/market_transactions_mvp.csv`, `data/seed_market.csv`
- 주요 필드: 지역명, 법정동코드, 주택유형, 거래유형, 거래년월, 거래가격 또는 보증금, 월세, 전용면적, 층, 건축연도
- 활용: 전세가율, 시세괴리율, 적정 전세가, 추정 매매가, 유사거래 신뢰도
- 공식 원천: 국토교통부 실거래가 공개자료, 공공데이터포털 RTMS API

### 4-3. 건축물대장 데이터

- 파일: `data/building_registry_mvp.csv`, `data/seed_building_registry.csv`
- 주요 필드: 주소, 도로명주소, 법정동코드, 건물명, 동명칭, 호명칭, 층, 주용도, 전유면적, 사용승인연도, 위반건축물 여부
- 활용: 주택 용도, 면적, 사용승인연도, 위반건축물 위험 신호
- 공식 원천: 정부24 건축물대장 발급·열람 안내, 국토교통부 건축물대장 정보 서비스

### 4-4. RAG 문서 데이터

- 파일: `data/rag_documents_mvp.json`
- 공식 출처 원장: `data/rag_official_sources.json`
- 포함 문서:
  - 주택임대차보호법
  - 주택임대차보호법 시행령
  - 공인중개사법
  - 부동산등기법 관련 안내 자료
  - 건축물대장 확인 안내 자료
  - HUG 전세보증금반환보증 안내문
  - 국토교통부 전세사기 예방 체크리스트
  - 지자체 전세사기 예방 안내문
  - 주택임대차 표준계약서
  - 중개대상물 확인설명서 양식

## 5. 전처리 원칙

1. 주소는 도로명주소, 지번주소, 법정동코드 기준으로 정리한다.
2. 주택유형은 아파트, 오피스텔, 연립다세대, 다가구, 단독주택 등으로 통일한다.
3. 금액 단위는 원 단위로 통일한다.
4. 면적 단위는 제곱미터 기준으로 통일한다.
5. 거래시점은 최근 1~2년 데이터를 중심으로 사용한다.
6. 유사 매물은 같은 법정동, 같은 주택유형, 비슷한 전용면적, 비슷한 건축연도를 기준으로 묶는다.
7. 유사 거래 건수가 부족한 경우 결과 신뢰도를 낮게 표시한다.
8. 실거래가 이상치는 평균값보다 중앙값, IQR, Z-score 등을 활용해 완화한다.

전처리 기준은 `data/preprocessing_rules.json`에 기계가 읽을 수 있는 형태로 저장했다.

## 6. 진단 로직

앱은 다음 위험 신호를 계산하거나 추출한다.

- 전세가율 과다
- 주변 시세 대비 보증금 괴리
- 근저당권
- 압류·가압류
- 신탁등기
- 임차권등기
- 최근 소유권 이전
- 위반건축물
- 다가구 선순위 보증금 미확인
- 등기부등본, 건축물대장, 확인설명서 미확인

위험 신호는 점수화되어 안전, 주의, 위험, 고위험, 검토불가 등급으로 표시된다. 유사거래 수와 원본 문서 확인 여부는 진단 신뢰도에 반영된다.

## 7. RAG 구성

RAG 원문 전체를 앱에 복제하지 않고, 공식 링크와 요약 chunk, 위험키, 응답 규칙을 분리해 저장했다. 이 방식은 저작권과 최신성 리스크를 줄이면서도 심사자가 공식 근거를 바로 열어 검증할 수 있게 한다.

- 요약 chunk: `data/rag_documents_mvp.json`
- 공식 출처 원장: `data/rag_official_sources.json`
- 제출용 링크표: `docs/OFFICIAL_RAG_SOURCE_LINKS.md`

## 8. 공식 API 수집 설계

공공데이터포털 API는 서비스키가 있어야 호출할 수 있다. 따라서 MVP에는 인증키 없이 실행 가능한 seed 데이터를 포함했고, 실제 운영 단계에서는 `scripts/collect_public_data.py`로 원천 XML을 수집해 `data/processed/` CSV로 정규화한다.

예시 실행:

```powershell
$env:DATA_GO_KR_SERVICE_KEY="발급받은_인증키"
python scripts/collect_public_data.py --lawd-cd 11500 --months 202511 202512
```

## 9. 배포 구조

Hugging Face Gradio Space로 배포한다.

- 앱 진입점: `app.py`
- SDK: `gradio`
- 실행 모델: PyTorch MLP, Pandas 유사거래 비교, 문서 AI, RAG 검색, 조건 분기 Agent
- 정적 포트폴리오 화면: `app/index.html`

이 구성은 심사자가 별도 설치 없이 브라우저에서 앱, 데이터셋, RAG 출처, 백서를 함께 확인할 수 있게 한다.

## 10. 한계와 확장 계획

- 현재 PDF 텍스트 추출은 브라우저 기반 MVP 수준이다. 운영 단계에서는 OCR과 PDF 파서를 서버 측으로 분리한다.
- 공공데이터 원천 수집은 서비스키가 필요하므로, 배포본에는 수집기와 공식 API 링크를 포함한다.
- 실제 전세사기 위험 판단은 법률 자문을 대체하지 않는다. 앱은 위험 신호를 안내하고 전문가 검토가 필요한 상황을 빠르게 알려주는 보조 도구로 사용한다.
