# 데이터 확보 현황과 남은 요청자료

확인일: 2026-05-20

이 문서는 관악구 전세 위험진단 MVP 구현 중 임의 생성 또는 추정으로 채운 부분을 공식 출처 기준으로 다시 점검한 결과다. API 키 없이 확인 가능한 공식 출처와 수집 경로는 레포에 고정했고, 실제 운영 정확도에 필요한 원천 데이터와 검증자료만 남은 요청자료로 분리했다.

## 추가로 남은 요청자료

1. 공공데이터포털 API 인증키
   - 필요 이유: 관악구 실거래가와 건축물대장 원천 행을 자동 수집하려면 `serviceKey`가 필요하다.
   - 신청처: [공공데이터포털](https://www.data.go.kr/)
   - 수집 대상: `LAWD_CD=11620`, 최근 24~36개월, 아파트/연립다세대/단독다가구/오피스텔, 매매/전월세 전체.

2. 국토부 실거래가 공개시스템에서 내려받은 관악구 CSV
   - 필요 이유: API 키가 늦으면 수동 CSV로 먼저 seed 데이터를 실제 데이터로 교체할 수 있다.
   - 다운로드 경로: [실거래가 공개시스템 자료제공](https://rt.molit.go.kr/pt/xls/xls.do?mobileAt=)
   - 조건: 서울특별시 관악구, 최근 1년씩 나눠서 다운로드, 건물유형별/거래유형별 CSV.

3. 실제 건축물대장 원천 데이터 또는 샘플 문서
   - 필요 이유: 주용도, 사용승인일, 면적, 위반건축물 표시를 실제 주소 기준으로 검증해야 한다.
   - 확보 경로: [건축물대장정보 서비스](https://www.data.go.kr/dataset/15004825/openapi.do?lang=ko), [정부24](https://www.gov.kr/), [세움터](https://www.eais.go.kr/)
   - 최소 필요 컬럼: 대지위치, 도로명대지위치, 시군구코드, 법정동코드, 주용도코드명, 전유/전용면적, 사용승인일, 위반건축물 여부.

4. 익명화된 실제 문서 PDF/이미지 10~30건
   - 필요 이유: OCR/사용자 입력 병합, 충돌 감지, 개인정보 마스킹의 현실 정확도를 확인해야 한다.
   - 문서 종류: 등기사항전부증명서, 건축물대장, 중개대상물 확인설명서, 가능하면 임대차계약서.
   - 제공 전 처리: 주민등록번호, 이름, 전화번호, 계좌번호, 상세 호수 등 개인정보 마스킹 권장.

5. 전문가 검토 기준표
   - 필요 이유: 현재 위험 점수와 등급은 MVP 규칙이며 법률 판단이나 보증 가입 가능성 확정이 아니다.
   - 검토자: 공인중개사, 부동산 데이터 분석가, 법률 전문가, HUG/보증 실무 경험자.
   - 검토 항목: 전세가율 임계값, 근저당+보증금 합산 위험 기준, 신탁/압류 강제 상향 기준, 다가구 선순위 보증금 처리.

6. 실제 사용자 리포트 피드백
   - 필요 이유: "위험", "고위험", "검토불가" 문구가 과도한 단정이나 법률 판단처럼 보이지 않는지 확인해야 한다.
   - 필요한 형태: 샘플 리포트별 사용자 이해도, 추가 확인 행동의 실행 가능성, 문구 수정 의견.
