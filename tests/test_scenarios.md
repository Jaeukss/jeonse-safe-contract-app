# 테스트 시나리오

## Case 1. 정상 OCR + 안전에 가까움

- 관악구 다가구
- 전세가율 낮음
- 등기부등본 OCR: 근저당 없음, 압류 없음
- 건축물대장 OCR: 위반건축물 아님

기대 결과: 현재 확인된 정보 기준 위험 신호가 적음

## Case 2. OCR 실패 + 체크박스 보완

- OCR 실패
- 체크박스: 근저당 없음, 압류 없음, 신탁 모름

기대 결과: 진단 가능, 단 문서 신뢰도 낮음

## Case 3. OCR과 체크박스 충돌

- OCR: 근저당 있음
- 체크박스: 근저당 없음

기대 결과: 충돌 감지 후 사용자 확인

## Case 4. 고위험

- 관악구 다가구
- 전세가율 90% 이상
- 신탁등기 있음
- 선순위 임차보증금 미확인

기대 결과: 고위험

## Case 5. 재진단

- SNAP-001: 등기부등본 미확인
- SNAP-002: 등기부등본 OCR 업로드 후 근저당 확인

기대 결과: 기존 스냅샷 유지, 신규 스냅샷 생성
