# 샘플 등기부 PDF 오판 Hotfix

## 원인

기존 패치의 `registry_parser.py`는 `말소`라는 단어가 등기부 전체에 있으면 전체 권리관계를 clear 처리했습니다.
샘플 PDF에는 `말소사항 포함`과 `3번 압류 말소`가 들어 있어, 근저당권과 전세권까지 `False`로 꺼지는 문제가 있었습니다.

## 수정

- `말소`를 전역 clear 키워드에서 제거했습니다.
- `기재사항없음`, `권리관계없음`, `을구사항없음`처럼 문서 전체가 비어 있음을 뜻하는 문구만 전역 clear로 봅니다.
- `has_active_attachment false`가 있으면 압류는 말소된 것으로 처리합니다.
- `has_active_mortgage true` 또는 채권최고액이 있으면 근저당권은 검출합니다.
- 채권최고액 변경 이력이 있으면 마지막으로 발견한 채권최고액을 우선합니다.
- 리포트 문서 신호 카드에 전세권등기, 소유권 변동 단서, 등기상 주의/특이사항을 추가했습니다.

## 샘플 PDF 기대 결과

- 근저당권: 검출
- 채권최고액: 390,000,000원
- 압류: 미검출/말소 처리
- 전세권등기: 검출
- 소유권 변동 단서: 검출
