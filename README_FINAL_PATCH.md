# 최종 OCR 권리관계/리포트 확장 패치

이 패치는 기존 `README.md`를 대체하지 않습니다. 저장소 루트에 별도 설명 파일로 추가하세요.

## 포함 범위

1. 등기부 OCR 권리관계 추출 확장 및 샘플 PDF 오판 수정
   - 근저당권, 채권최고액, 압류, 가압류, 신탁등기, 임차권등기, 전세권등기, 소유권 변동 단서, 등기상 주의/특이사항 추출
   - `말소사항 포함`, `압류 말소` 같은 일부 말소 문구가 등기부 전체를 권리 없음으로 만드는 문제 수정
   - 샘플 PDF의 `has_active_mortgage true`, `has_active_attachment false` 같은 추출용 필드도 우선 반영

2. OCR 결과 확인 및 보완 입력 자동 채움
   - 문서 추출값을 `OCR 결과 확인 및 보완 입력` 화면에 먼저 자동 반영
   - 사용자가 틀린 값만 수정하고 진단 가능

3. 기본정보 입력 UI 확장
   - 건물 동(`unit_dong`), 호수(`room`), 계약유형(`contract_type`) 입력 추가
   - 문서 추출 기본정보가 있으면 기본 입력칸 자동 덮어쓰기 대상에 포함

4. 리포트 확장
   - RAG Evidence Card를 Streamlit 리포트 화면에 출력
   - RAG Evidence Card를 Markdown 리포트에 출력
   - 근저당권, 압류, 가압류, 위반건축물, 임차권등기, 신탁등기, 전세권등기, 등기상 주의/특이사항, 최근 소유권 변동 신호를 문서 신호/위험 점수/충돌 감지/병합/다음 행동/RAG 근거까지 연결

5. 노이즈 OCR 보강
   - 이미지/PDF OCR 전처리 후보를 여러 개 만들고 가장 품질이 높은 텍스트를 선택
